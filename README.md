# Pinpoint: AGLC4 Citation Engine

A single-page, browser-only generator for AGLC4 (4th ed) footnotes, ibid and subsequent
references, in-text mentions and bibliography entries.

- No build step and no server: open `index.html` or host it on GitHub Pages.
- Each visitor's library and footnotes are saved in their own browser (`localStorage`).
  Nothing is sent anywhere.
- Independent study aid, not affiliated with the Melbourne University Law Review Association.
